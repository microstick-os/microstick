DHCP & local addresses

Changing the stick address or disabling DHCP requires confirmation within 2 minutes. Reconnect or renew your IP, then open the new panel address. Otherwise the previous settings return automatically.

Names & reserved addresses

Leave the IP empty to save only a device name. A reserved address takes effect when the client renews DHCP.

Modem ports

Allow access through the connected Wi-Fi network to programs running on the modem.

Internet access rules

Choose a device to block its internet access, then save. For selected websites or services, use advanced settings. Local panel access remains available.
